# Clarity PV 自動記入（Google Apps Script）

「LPヒートマップ」シートの B列（PV数）に、前日分の LP セッション数を毎日自動で記入する。
スクロール別の到達人数は Clarity API で取得できないため、ヒートマップ画面から手入力する。

## セットアップ

1. 対象スプレッドシートで「拡張機能 > Apps Script」を開き、`Code.gs` の中身を貼り付けて保存
2. 「プロジェクトの設定 > スクリプト プロパティ」に以下を追加
   - `CLARITY_TOKEN`: Clarity の「設定 > データのエクスポート」で発行した API トークン
   - `LP_URL`: LP の URL に含まれる文字列（例: `/lp/gift`）
3. プロジェクトのタイムゾーンを `Asia/Tokyo` にする（プロジェクトの設定）
4. `recordYesterdayPv` を一度手動実行し、権限を許可して B列に値が入るか確認
5. `createDailyTrigger` を一度手動実行（毎日 0〜1 時に自動実行される）

## 注意

- 値は Clarity の **セッション数**。GA4 の PV とは一致しない。
- `numOfDays=1` は「実行時点から過去24時間」で、暦日ぴったりではない。0 時台実行で前日分とみなしている。
- API は 1 日 10 リクエストまで。手動実行の繰り返しに注意。
- B列に値が既にある日は上書きしない。
- トークンはスクリプト プロパティにのみ置く。コードやシートに直接書かない。
