## 毎日実行させる指示文（Claude in Chrome / デスクトップアプリのスケジュールに登録）

```
Clarity の数値を Google スプレッドシートに記入してください。読み取りと記入以外の操作（設定変更・削除・共有）は一切しないこと。

■ 記入する日の決め方
1. https://docs.google.com/spreadsheets/d/1IWlkOrVyqNjxx_WXbFP_N9HuceOdEkRiDDPRsIgshgo/edit?gid=987719969 の「LPヒートマップ」シートを開く。
2. 今日（日本時間）より前の日付で、B列が空欄の行を探す。今日の行は対象外（データが揃っていないため）。
   - 対象は直近7日以内に限る（それより古い空欄は触らず、報告だけする）。
   - 該当する日を古い順に1日ずつ、以下の手順で処理する。該当がなければ何もせず「記入対象なし」と報告して終了する。

■ 1日分の処理（対象日 = D）
3. https://clarity.microsoft.com を開き、プロジェクト「田丸屋_通常LP」を選ぶ。
4. 上部メニュー「ヒートマップ」を開き、次を設定する。
   - 日付（上部の日付欄）: D の 00:00 - D の 23:59（1日だけ）
   - 「閲覧済み URL」フィルター: https://mizusawaudontamaruya.jp/lp/ （既に設定済みならそのまま）
   - デバイス切替（左上の3つのアイコン）: 右端のスマートフォンのアイコン
   - 表示切替: 「スクロール」
   いずれかを設定できない場合は、その日は記入せずに止まって報告する。
5. ヒートマップ下部の「◯ ページ ビュー」の数値を読む → S とする。
   S が 0、またはヒートマップが表示されない場合は、B列に 0 を入れ、AQ列（メモ）に「Claude記入: データなし」と書いて次の日へ進む。
6. 左側パネル「スクロール データ」の表を読む。列は「% スクロールしました」「# 人以上の訪問者」「% ドロップオフ」。
   - 「# 人以上の訪問者」が「29 (69.05%)」なら、人数 = 29、割合 = 69.05%。
   - 5%〜100% の全20行を読む。表は途中で切れているので、パネルを下までスクロールして 100% まで読むこと。
   - 計算はしない。画面の数値をそのまま使う。読めない行は空欄にする。
   - 「% ドロップオフ」は記入しない。
7. 確認: 割合 ≒ 人数 ÷ S になっているか（例: 29 ÷ 42 = 69.05%）。合わなければその日は記入せずに報告する。
8. シートの A列が D の行に記入する。
   - B列: S
   - 人数/割合: 5%→C/D, 10%→E/F, 15%→G/H, 20%→I/J, 25%→K/L, 30%→M/N, 35%→O/P, 40%→Q/R, 45%→S/T, 50%→U/V, 55%→W/X, 60%→Y/Z, 65%→AA/AB, 70%→AC/AD, 75%→AE/AF, 80%→AG/AH, 85%→AI/AJ, 90%→AK/AL, 95%→AM/AN, 100%→AO/AP
   - 割合は % 表記で入力する（例: 69.05%）。
   - AQ列（メモ）: 「Claude記入・SPのみ」。空欄にした行があれば「／◯%地点 読取不可」を追記。
   - 既に値が入っているセルは上書きしない。

■ 報告
9. 処理した日ごとに、記入した値の一覧（地点・人数・割合）を表で報告する。人数が 5%→100% で単調に減っていない箇所があれば指摘する。
   ログインが切れている・プロジェクトが見つからない場合は何も記入せずに止まり、その旨を報告する。
```

## 運用ルール

- 最初の 1 週間は、毎日 Clarity 画面とシートを人が目視で突き合わせる。その後も週 1 回は抜き取り確認する。
- 到達割合は単調に減るはず（5% ≥ 10% ≥ … ≥ 100%）。逆転していたら読み取りミスを疑う。
- Clarity の UI が変わって手順が合わなくなったら、この手順書を更新する。
