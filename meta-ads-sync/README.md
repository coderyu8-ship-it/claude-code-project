# Meta広告 日次自動入力（Google Apps Script）

対象シート「田丸屋様_Meta広告の数値管理」→ タブ「Meta広告の数値」。
毎朝9時台に前日分の B/C/D/J/K/M 列を、日付（A列）が一致する行へ書き込む。率・単価・合計は既存の数式のまま。

## 設置手順
1. シートで「拡張機能 → Apps Script」を開き、`Code.gs` を貼り付ける。プロジェクト設定で「appsscript.json を表示」にして、`appsscript.json` の内容に置き換える。
2. アクセストークンを発行する（**システムユーザー推奨**。通常のユーザートークンは約60日で失効する）
   - ビジネス設定 → ユーザー → システムユーザー → 追加（管理者）
   - 「アセットを割り当て」で広告アカウント 825232673399116 を選び、「レポートを表示」以上の権限を与える
   - 「トークンを生成」→ 権限 `ads_read` にチェックを入れて生成する
3. Apps Script の「プロジェクトの設定 → スクリプトプロパティ」に `META_ACCESS_TOKEN` = トークン を追加する。
4. `listActionTypes` を実行し、実行ログの action_type 一覧から 商品詳細／v2／v4 に当たるものを `CONFIG.COLUMNS` の `REPLACE_ME_*` に入れる。
   カスタムコンバージョンなら `offsite_conversion.custom.<ID>` の形で出る。
5. `syncMetaAds` を手動で1回実行し、管理画面の数値と一致するか確認する。
6. `installTrigger` を1回実行する（毎日9時台に実行されるトリガーが作成される）。

## 注意点
- 列プリセット「商品ページ確認・購入数」はAPIからは参照できないため、action_type で個別に指定している。
- GASの時刻トリガーは「9時ちょうど」ではなく「9〜10時のどこか」で実行される（仕様）。
- 月が替わったら、これまでどおり月ブロック（合計行＋日付行）を手動で作る。日付行が無い場合はエラーになり、Googleから失敗通知メールが届く。
- Metaの数値は数日後まで遡って変動する。気になるなら `DAYS_BACK` を 3 にする。
