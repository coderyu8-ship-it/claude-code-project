# Clarity スマートイベント → 「Meta広告の数値」シート 転記指示

LP ヒートマップの離脱率を毎日記入している Cowork の定期タスク（Clarity を画面で読む方式）に、
下の「毎日の追加指示」を貼り付けて使う。過去分は「過去分の一括記入」を 1 回だけ実行する。

- Clarity プロジェクト：田丸屋_通常LP（ID: xvfqmhec8j）
- スプレッドシート：田丸屋様_Meta広告の数値管理（1IWlkOrVyqNjxx_WXbFP_N9HuceOdEkRiDDPRsIgshgo）
- タブ：「Meta広告の数値」

| 列 | 見出し | 書く値 |
| --- | --- | --- |
| Q | 離脱防止ポップアップ表示数 | `exit_popup_show` のセッション数 |
| R | 離脱防止ポップアップクリック数 | `exit_popup_click` のセッション数 |
| T | フローティングバナー表示数 | `floating_banner_impression` のセッション数 |
| U | フローティングバナークリック数 | `floating_banner_click` のセッション数 |
| S / V | クリック率 | 既存の数式。**書き込まない** |
| W | メモ | 取得失敗時のみ、既存の文章の末尾に追記 |

## 毎日の追加指示（定期タスクのプロンプト末尾に貼る）

```
【追加作業：離脱防止ポップアップ・フローティングバナーの記録】
離脱率の記入が終わったら、続けて次を行う。離脱率の記入内容・手順は一切変えないこと。

1. Clarity「田丸屋_通常LP」（xvfqmhec8j）のダッシュボードを開き、期間を「昨日」（日本時間）にする。
   デバイス・URL などのフィルターは掛けない（対象イベントは LP でしか発生しない）。
2. 「スマートイベント」から次の 4 つの数字を読む。数字は「イベントが起きたセッション数」。
   exit_popup_show / exit_popup_click / floating_banner_impression / floating_banner_click
   一覧に出ていないイベントは 0 とする（空欄にしない）。
3. スプレッドシート 1IWlkOrVyqNjxx_WXbFP_N9HuceOdEkRiDDPRsIgshgo の「Meta広告の数値」タブで、
   A 列が対象日（YYYY/MM/DD）の行を探す。
   - Q 列 = exit_popup_show、R 列 = exit_popup_click、
     T 列 = floating_banner_impression、U 列 = floating_banner_click
   - S 列・V 列（クリック率の数式）、月合計・累計の行、その他のセルには書き込まない。
4. 重複防止：その行の Q・R・T・U のどれかに既に値が入っていれば、何も書かずにスキップする。
5. 取得失敗：数字が読み取れなかったとき（画面が開けない、ログイン切れ、読み込みが終わらない、
   スマートイベントが表示されない、など）は、推測した値を入れず Q・R・T・U は空欄のままにする。
   W 列（メモ）の既存の文章を消さずに、末尾に「／Clarityイベント取得失敗：<具体的な理由>」を追記する
   （W 列が空ならそのまま「Clarityイベント取得失敗：<理由>」と書く）。
   対象日の行が見つからないときは書き込まず、報告だけする。
6. 報告：対象日、書いた行番号、Q・R・T・U の値、S・V に表示されたクリック率を 1 行で報告する。
   スキップ・失敗のときはその旨と理由を書く。
禁止：Clarity・GTM の設定変更、シートの列・タブ・数式・書式の変更、既存の値の上書き。
```
