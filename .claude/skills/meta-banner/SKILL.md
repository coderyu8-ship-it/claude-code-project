# Meta広告バナー作成（企画案＋画像作成プロンプト）

一言の依頼から、**企画3案（参考バナー付き）→推奨1案→画像作成プロンプト**までを、途中で確認を挟まずに一気に出す。
画像の生成・ダウンロード・ロゴ合成は、このスキルでは行わない（プロンプトを受け取ったユーザーが Gemini などで実行する）。

## 0. 前提ファイルを読む

1. `brands/<brand>/brand.md` を読む。ブランドの指定がなければ `brands/` 配下が1つならそれを使い、複数あれば聞く。
2. brand.md の「勝ちパターン」「NG」「要確認の訴求」「商品写真の対応表」を、以降すべての判断基準にする。
3. 最新の実績レポートがあれば Drive で検索して読む（例：`fullText contains '<ブランド名>' and fullText contains 'バナー分析'`）。brand.md より新しければ、そちらを優先する。

## 1. 参考バナーを集める

各案には、構図・雰囲気の手本になる **参考バナーを1枚ずつ** 添える。探す順番：

1. ユーザーが会話に添付・指定した画像（最優先。その案の参考にする）
2. `brands/<brand>/refs/` にある過去バナー（例：`ver23_1x1.jpg`）。実績上位のもの（brand.md の勝ちパターン）を優先
3. Drive の過去バナー（ファイル名 `ver<番号>` などで検索）。見つかったら `brands/<brand>/refs/` に保存して使う
4. 該当がなければ、`brands/<brand>/assets/` の商品写真を参考画像にし、「過去バナーなし」と明記する

参考バナーは必ず Read で中身を見てから使い、「何を真似るか（構図・トーン・文字位置）」「何を変えるか」を言葉にする。

## 2. 調べる（CLAUDE.md の常時ルール）

作る前に Web 検索で確認する。
- 時期の外部要因：季節行事・商戦（お歳暮、年末年始、母の日など）、曜日・時間帯、気温
- LP の現状：価格・キャンペーン・表記の変更（WebFetch で遷移先LPを確認）

## 3. 企画3案を出す

各案に次の項目を書く。
- **参考バナー**：Google ドライブの URL（`https://drive.google.com/file/d/<id>/view`）＋真似る点／変える点。Drive にない画像だけローカルパスにする
- 狙い（誰の、どんな気持ちに刺さるか）
- 写真（brand.md の勝つ写真の条件に合うもの。実写素材のファイル名を指定する）
- メインコピー（全角15字前後）／サブコピー（全角30字以内）／CTA
- 根拠（過去の実績の数値、または調べた外部要因。出典URL付き）
- 検証方法（何と比べて、何を見て判断するか）

**推奨案を必ず1つ選び、理由を書く。** 実績がある勝ちパターンから1要素だけ変える案を優先する（変える要素が多いと、何が効いたのか判別できない）。

## 4. 画像作成プロンプトを出す

企画案の直後に、**3案すべて**について画像作成プロンプトを出す（推奨案を先頭に）。確認は挟まない。
各案とも、次の2本をコードブロックで出す。プロンプト①には、どの参考バナーを添付するかを書き添える。

プロンプト①（写真。参考バナーを添付して使う）：
```
添付の画像をもとに編集した画像を生成してください。
【残すもの】器、料理（<料理>。具材：<具材>）、箸上げ、構図
【消すもの】すべての文字、ロゴ、ボタン
【変えるもの】<トーン（例：金曜の夜。窓の外は暗く、遠くに暖かい灯りのボケ。器に暖色の光。湯気を見せる）>
【構図】上部35%は、あとで文字を置くための暗く整理された余白にする。写真のようにリアルな料理写真。文字は一切入れない。<比率>
```

プロンプト②（文字入れ。①の直後に続けて送る）：
```
直前に生成した画像をそのまま使い、写真は変えずに文字だけを入れてください。
【上部の暗い余白】中央揃え、2行、生成り色の明朝体で「<1行目>」「<2行目>」
【右下】オレンジ色の角丸ボタンに白い文字で「<CTA>」
【左下】ロゴをあとで貼るので、何も置かず暗めの余白にする
この3つ以外の文字・ロゴ・記号は一切入れない。文字は一字一句正確に。<比率>
```

プロンプトのルール：
- **ロゴは AI に描かせない。** プロンプトには必ず「左下は空ける」を入れ、ロゴは後から正規データ（brand.md の正規ロゴ）を `tools/banner-gen/add_logo.py` で貼る、と添える（過去に創業年の誤記が5本出た）
- 文字は画像の20%程度以内。写真が主役
- 料理写真を AI で生成する場合は、その旨と「器・具材が実物と一致しているか要確認」を添える
- 4:5 / 9:16 が必要なら、比率だけ変えた版も出す。9:16 は「上下14%に文字を置かない」を加える

## 5. 出力の形

- 会話に直接出す。あわせて `output/<brand>/<YYYYMMDD>/plan.md` に同じ内容を保存する（output/ はコミットしない）。参考バナーは Drive の URL で示す
- 最後に出す前チェックを付ける：
  - [ ] ロゴの創業年が brand.md の正しい値（田丸屋は **ESTD.1582**）
  - [ ] 価格・送料・熨斗の表記が、当日のLPと一致
  - [ ] 「要確認の訴求」「NG」を使っていない
  - [ ] 誤字脱字、商品名の表記（LP表記に合わせる）
- 画像のファイル名の目安：`<ブランド>_<YYYYMMDD>_<案名>_<比率>.png`

## 6. 終わったら更新する

- 新しく素材や参考バナーを特定したら、brand.md の「商品写真の対応表」と `refs/` に追記する
- 実績が出たら、brand.md の「勝ちパターン」を更新する
